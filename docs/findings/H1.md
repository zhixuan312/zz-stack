# H1 — the harness records every stakeholder turn twice (harness defect, not the flow's)

ladder-round.sh appends the user's reply to turns.jsonl, and then hands the same text to
ladder-turn.sh, which appends it again as its own first act. From turn 2 onward every
stakeholder row is duplicated.

Nothing downstream crashes, which is why it survived a round: the digest just prints the
same line twice, and any count of "how many turns did the user take" is double from turn 2.
A harness whose transcript miscounts is one whose findings cannot be trusted about volume —
and volume is half of what a report like evolve-report ranks on.

Not fixed while a round is running: bash reads a script incrementally, so editing one
mid-execution can corrupt the run that is producing the evidence.
