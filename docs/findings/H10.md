# H10 — the noise floor, measured: 0.436 points, and what it makes readable

sm-intent 1.0 was run over the same eight requirements three times, each into a store archived
clean beforehand, and every run scored by the same rubric and the same judge. Nothing changed
between them but the run itself.

    id    rep1  rep2  rep3   range
    r02   3.20  4.20  3.80   1.00
    r05   3.40  3.60  4.20   0.80
    r10   3.40  3.60  3.40   0.20
    r16   3.60  3.60  4.60   1.00
    r23   3.00  3.80  4.00   1.00
    r25   4.00  3.40  3.60   0.60
    r26   4.00  4.00  4.60   0.60
    r28   3.20  3.80  4.20   1.00

**Within-requirement standard deviation: 0.436 of 5.** The median requirement moves a full point
between runs of a skill that did not change.

## What this makes readable, and what it retires

Two standard errors of the corpus mean, at one run per requirement:

     8 requirements   a delta below 0.31 is not distinguishable from noise
    28 requirements                 0.16
    30 requirements                 0.16
    30 requirements x 3 runs        0.09

So:

- **The differences BETWEEN skills survive.** sm-plan 4.53, sm-select 4.33, sm-spec 3.86,
  sm-intent 3.43 — the gap from best to worst is 1.10, roughly seven times the floor at n=30.
  sm-intent being the weakest is a real finding, and so is which dimension it is weakest on.
- **Every A/B on a held-out subset of eight is retired.** The threshold there is 0.31 and the
  measured delta was 0.000, on five requirements that were contaminated anyway (H9). It was never
  going to be able to answer the question it was asked.
- **A/B belongs on the whole corpus.** Thirty requirements at one run each detects 0.16, which is
  a plausible size for one guideline's worth of improvement. Three runs of thirty would reach
  0.09, at three times the cost, and that is a trade to make deliberately rather than by default.

## One thing three points cannot settle

The corpus means came out 3.475, 3.750, 4.050 — monotonically increasing. That ordering happens
by chance about one time in six, so it is not evidence of drift, and there is no mechanism in
sight: `_knowledge` is empty and the ledger is three lines, so the platform is not learning
between repeats. It is recorded here because if a fourth and fifth repeat continue the climb it
stops being a coincidence and becomes the most important thing on this page.

## The rule this sets

No change to a skill is called an improvement or a regression unless its corpus-mean delta clears
the floor for the number of requirements it was measured on. Below that the verdict is UNTESTED —
a third verdict, and the honest one — not a small number reported with a direction.
